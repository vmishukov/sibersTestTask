# File Loader for Sibers

A file downloader with concurrent segmented downloading, background progress saving, pause and resume support, and a built-in file viewer.

---

### Concurrent Segmented Downloads

Supports concurrent file downloading with segmentation and automatically saves download progress when the app enters the background.
